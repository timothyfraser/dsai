# Templates: blank copies for a new repo

**Starting a module project in this repo?** Copy the four files below to the repo root first
(`SPEC.md`, `CONTRACT.yaml`; `CLAUDE.md` and `AGENTS.md` already exist here), then replace every `<...>`.

These are blank, generic copies for starting a **new** repo elsewhere:
[`SPEC.md`](SPEC.md) (what the tool is), [`CONTRACT.yaml`](CONTRACT.yaml) (the task ledger),
[`CLAUDE.md`](CLAUDE.md) and [`AGENTS.md`](AGENTS.md) (agent instructions; keep the two in step).
Copy all four to the new repo's root, replace every `<...>`, and work one task at a time with the
[`contract-ledger`](../skills/contract-ledger/SKILL.md) skill.
