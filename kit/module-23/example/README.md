# Street Count

An example team repo for the Finale lab's checks: a traffic forecast for a city mobility planner.

## What it is
Ask for a street counter, a day and an hour; get the expected count, and a warning when it should not be trusted.

## Install
Copy `.env.example` to `.env` and fill in your own values. Install the packages listed in `SPEC.md`.

## Run
Start the API, then open the page it prints. The first request after a sleep takes a few seconds.

## Check
Run the smoke test and the error check. Their output goes in `runs/`.

## Hand-off
`SKILL.md` tells the next team's coding agent how this repo is laid out and which checks must pass.
