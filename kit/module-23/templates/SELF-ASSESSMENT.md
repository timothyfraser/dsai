# Self-assessment: the four columns

Fill one row per column. Every claim names the file of evidence a reviewer can open.
A claim with no file named does not count, however true it is.

| Column | The question | Our answer | Evidence |
|---|---|---|---|
| Build | Did an agent build it against a contract we wrote? | | contract: `SPEC.md` |
| Verify | How do we know it works, and that it is the right thing? | | check output: files in `runs/` |
| Productionise | Where does it run, why there, and what happens when it sleeps or breaks? | | deploy notes: `README.md` |
| Explain | Can we say what it is, why this architecture, what it costs, where it fails? | | stand-up: `STANDUP.md` |
