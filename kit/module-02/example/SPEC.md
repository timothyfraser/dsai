# SPEC

## Goal
A small Shiny app that looks up a character in a public API and shows the rows in a table.

## Who it is for
A classmate who wants to try the API without writing a request.

## Contract
1. The app starts with one command: yes
2. A real name returns real rows in the table: yes
3. An empty field shows a message and the app stays running: yes
4. The README says how to install, run, and which key is needed: yes
