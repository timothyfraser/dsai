# The check script's fixture

Course kit, module 12. Two tiny `ui-lab/` folders, so `check.py` can be tried with no app,
no browser and no model. `good/` is a finished lab for a made-up maintenance-log question
page: it passes. `bad/` is the same lab half done: no latency budget, a raw colour in the
app's CSS, a grey that fails contrast, two critique rounds, one alternative, and an animation
that ignores reduced motion. It fails, and each failure says why. The screenshots are 1-pixel
placeholders: the script checks that they exist, and a person looks at real ones.
